## 1. 서비스 정의

한국관광공사 OpenAPI로 확인한 관광지를 기준점으로 삼고, 유효시간이 남은 날씨·혼잡·대기·주차·도로·현장 사진을 결합하여 여행자에게 `지금 가기`, `조금 기다리기`, `근처 대안 보기` 중 하나를 근거와 함께 제시합니다.

서비스 한 줄 설명:

> 한국관광공사 관광정보에 최신 현장 변수를 결합하여, 지금 갈지·기다릴지·어디로 바꿀지 알려주는 근거 기반 AI 여행 가이드

전국의 장소 검색은 처음부터 열어 두되, 최신 근거가 없는 장소는 `최근 확인 정보 없음`으로 표시합니다. 지역별 데이터 밀도는 단계적으로 높이지만 제품 범위는 전국입니다.

## 2. 사용자 문제와 해결 흐름

1. 여행자가 장소 또는 해시태그를 검색합니다.
2. 앱은 내부 장소와 수동 검증된 한국관광공사 `contentId` 매핑을 확인합니다.
3. 유효시간이 남은 날씨·혼잡·대기·주차·도로·현장 제보만 판단 입력으로 사용합니다.
4. 출처 충돌, 필수 변수 누락, 샘플·만료 데이터가 있으면 추천을 보류합니다.
5. 판단 카드가 `지금 가기`, `조금 기다리기`, `근처 대안 보기` 중 안전한 동선을 보여줍니다.
6. 사용자는 최신 사진을 확인하거나 같은 지역의 대안을 비교합니다.

## 3. 한국관광공사 OpenAPI 활용

### 현재 구현

- `areaBasedList2`: 지역·콘텐츠 유형별 관광지 후보 수집
- `locationBasedList2`: 내부 장소 좌표 주변의 대안 관광지 후보 수집
- 수집 결과의 `contentId`, 명칭, 주소, 좌표, 수정시각 정규화
- 운영자만 실행 가능한 수집 경로에서 수동 검증 후 내부 장소와 매핑
- 공개 장소 상태 응답에 검증된 관광공사 관광지 기준 정보와 출처 표시
- 정적 관광정보를 실시간 혼잡·운영 상태로 오해하지 않도록 현재 상태 집계에서 제외

### 기능심사 전 추가

- `detailCommon2`, `detailIntro2`: 소개·이용 정보 보강
- `searchFestival2`: 행사 기간과 장소 맥락 보강
- 대안 후보별 거리·운영시간·카테고리 적합성 정렬
- 이미지 사용은 콘텐츠별 공공누리 유형을 저장·표시할 수 있을 때만 활성화

한국관광공사 데이터는 단순 로고 노출용이 아니라 `어떤 관광지를 판단하고 어떤 대안을 제시하는가`를 결정하는 기준 데이터입니다.

## 4. AI와 안전 설계

현재 앱에는 모델 장애·비용 차단 상황에서도 동작하는 결정론적 안전모드가 구현되어 있습니다. 안전모드는 다음 원칙을 강제합니다.

- 샘플·만료·누락 데이터로 현재 상태를 만들지 않습니다.
- 출처가 충돌하면 `조금 기다리기`로 보수적으로 전환합니다.
- 혼잡 근거가 있고 대안이 있을 때만 `근처 대안 보기`를 제시합니다.
- 관광공사 매핑이 없으면 `TourAPI 관광지 매핑 확인 필요`를 표시합니다.
- 관광공사 정적 정보의 수정시각을 현장 관측시각처럼 표시하지 않습니다.

기능심사 전에는 구조화된 판단 결과를 기반으로 AI가 카드형 설명과 대안 이유를 개인화합니다. 모델 출력은 JSON 스키마로 제한하고, 위 안전모드가 검증을 통과한 문장만 화면에 노출합니다. 모델이 실패하거나 비용 방어가 작동하면 현재 구현된 안전모드 문구로 즉시 대체합니다.

## 5. 비용·공격 방어

- TourAPI 키는 Worker 환경변수에만 저장하고 브라우저에 전달하지 않습니다.
- 사용자의 화면 열기마다 TourAPI를 호출하지 않습니다. 운영자 수집 또는 예약 수집 결과를 캐시·D1에서 읽습니다.
- 위치 기반 검색 반경은 10~20,000m, 페이지당 최대 100건으로 제한합니다.
- 수집 경로는 관리자 인증, 요청 제한, 전역 API 비용 가드의 보호를 받습니다.
- 기존 60% 경고, 70% 축소, 80% 비필수 API 중단 정책을 그대로 적용합니다.
- 80% 방어 시에도 정적 장소 위치와 `최근 확인 정보 없음` 화면은 유지합니다.

## 6. 화면 설계

장소 상세 상단 순서:

1. 장소·사진 요약
2. 기존 방문 판단
3. `AI 여행 변수 대응 · 안전모드` 카드
4. 관광공사 관광지 기준 정보와 콘텐츠 ID
5. 판단에 사용된 출처·관측시각
6. 최신 사진·제보·해시태그·근처 대안

판단 카드에는 공모전 기능 키워드인 `#실시간`, `#여행가이드`, `#연관관광지추천`, `#카드뉴스형답변`을 표시합니다.

## 8. 평가 하네스

명령:

```bash
pnpm eval:travel-guide
```

현재 8개 필수 시나리오를 검증합니다.

- 유효한 긍정 근거 → 지금 가기
- 혼잡 + 대안 있음 → 근처 대안 보기
- 혼잡 + 대안 없음 → 조금 기다리기
- 필수 날씨 누락 → 조금 기다리기
- 출처 충돌 → 조금 기다리기
- 최신 근거 없음 → 판단 보류
- 샘플 → 판단 보류
- 비용 보호 디렉터리 모드 → 판단 보류
